**Category-First Organization**: Grouped products by categories and subcategories with custom emoji icons, sort orders, and distinct color badges.- **Universal Instant Search**: Debounced, multi-token, case-insensitive search across product names, categories, and attributes.- **Unit / Pack Size Heuristics**: Automatic extraction and parsing of weights and packaging from product names (e.g., `500ml`, `1kg`, `250g`, `2L`, `1 pc`, `pcs/kg`).### 🔍 Blinkit-Style Product Detail View (PDP)- **Horizontal Swiping**: Seamless swipe pager to browse next/previous products in the active category.- **Photo Carousel**: Paged product photos with animated floating dots indicator.- **Pinch-to-Zoom Modal**: Full-screen image viewer with gesture pinch-to-zoom, pan, double-tap zoom reset, and fast close actions.- **Streamlined Pricing Display**: Direct side-by-side display of Cost Price and Selling Price without redundant badges.### 💰 Dual Pricing & Custom Tiers- **Integer Paise Precision**: All calculations handled in integer paise (`₹1.00 = 100 paise`), eliminating floating-point rounding errors.- **Dual-Market Pricing**: Side-by-side Cost Price (PATWARI rate) and Selling Price (BISRAKH rate).- **Price Formatting**: Flexible string formatting supporting fractional units, per-kg rates, and raw price annotations.### 🛒 Purchase List & Restocking- **Dedicated Cart Tab**: Real-time purchase list tracking items to reorder or purchase from wholesalers.- **Fast Quantity Steppers**: One-tap addition, subtraction, and custom numerical quantity entry.- **Live Cost Calculation**: Instant total cost calculation based strictly on Cost Price.- **Safe Cart Clearing**: Confirmation dialog protecting accidental cart resets.### 🗑️ 2-Stage Soft Delete & Recycle Bin- **Safe Deletion Flow**: Moving products to the Recycle Bin preserves them safely for 15 days before permanent deletion.- **Countdown Indicators**: Live badges showing exact remaining days or hours before automatic expiration.- **Multi-Item Batch Actions**: Select multiple items with "Select All / Deselect All" to batch Restore or Delete Permanently.- **Full Detail Inspection**: Tapping any trashed item opens the exact same full-featured product detail view with photo swiping and zoom.- **Automated Background Cleanup**: Android `WorkManager` periodically purges trashed products exceeding the 15-day threshold.### ⚡ Offline-First & Real-Time Cloud Sync- **Local SQLite / Room Engine**: 100% functional without an internet connection — instant app startup and search.- **PostgreSQL & Supabase Sync**: Two-way catalog synchronization keeping stock, products, and prices in sync.- **Realtime WebSocket Publications**: Listens to PostgreSQL change data capture (CDC) for live cross-device catalog updates.- **Conflict-Safe Merging**: Preserves local trashed status and avoids overwriting soft-deleted items during background cloud pulls.### 🖼️ Photo & Cloud Storage Management- **Supabase Storage Integration**: Uploads high-resolution product photos to the `product-images` storage bucket.- **Automatic Image Compression**: Downsamples and compresses camera/gallery images to JPEG $\le$ 500 KB before upload.- **Cache Invalidation**: Automatically evicts stale photos from Coil's memory and disk caches when photos are updated or deleted.- **Bulk Image Uploader**: Includes [`bulk_upload_images.py`](bulk_upload_images.py) script for batch uploading local product photos directly to Supabase Storage.### 🔒 Security & Admin Controls- **Biometric Authentication**: Fingerprint and Face Unlock integration via AndroidX Biometric.- **Owner-Device Recognition**: Hidden multi-tap gesture (6-tap sequence) to register authorized owner devices.- **Salted PIN Verification**: Fixed fallback admin PIN (`8810`) and PBKDF2 hash verification protecting admin functions.### 🧮 Kirana Calculator- **Dual-Mode Grocery Calculator**:  - **Price-to-Weight**: Calculate exact weight for a customer's money amount (e.g., *"give me ₹50 of ₹120/kg Ghee"* $\rightarrow$ `416.7g`).  - **Weight-to-Price**: Calculate exact payable price for custom weight (e.g., `350g` of `₹80/kg` Dal $\rightarrow$ `₹28.00`).- **Standard Keypad & Math Evaluation**: Built-in arithmetic solver supporting additions, subtractions, and multiplications.### 🚀 Self-Updating App Engine- **Direct GitHub Releases Integration**: Background update engine checks `version.json` on GitHub.- **In-App Download Progress**: Visual progress bar tracking APK download bytes.- **Automatic Install Prompt**: Launches the Android package installer via secure `FileProvider`.### 💾 Backup & Restore- **Portable JSON Backups**: Complete catalog export and import using Android's Storage Access Framework.---## 🛠️ Tech Stack| Layer | Component | Description || :--- | :--- | :--- || **Language** | Kotlin 2.0+ | Modern idiomatic Kotlin || **UI Framework** | Jetpack Compose | Declarative UI Prerequisites- **Android Studio**: Ladybug (2024.2.1) or newer- **JDK**: Java 17- **Android SDK**: `minSdk 26` (Android 8.0+), `compileSdk 35` (Android 15)### 2. Clone the Repository```bashgit clone https://github.com/myselflovekr/Grocy.gitcd Grocy```### 3. Configure `local.properties`Copy [`local.properties.example`](local.properties.example) to `local.properties` in the project root:```bashcp local.properties.example local.properties```Edit `local.properties` with your Android SDK path and Supabase credentials:```propertiessdk.dir=C\:\\Users\\<YourUsername>\\AppData\\Local\\Android\\Sdk# Supabase Backend ConfigurationSUPABASE_URL=https://your-project.supabase.coSUPABASE_ANON_KEY=your-supabase-publishable-or-anon-key# Keystore Release Signing Configuration (Optional for debug, required for release signing)RELEASE_STORE_FILE=release.keystoreRELEASE_STORE_PASSWORD=your-store-passwordRELEASE_KEY_ALIAS=your-key-aliasRELEASE_KEY_PASSWORD=your-key-password```> **Note**: `local.properties` is strictly ignored by `.gitignore` to prevent sensitive credentials from ever being committed to version control.### 4. Supabase Backend Setup1. Create a project at [supabase.com](https://supabase.com).2. Navigate to the **SQL Editor** in your Supabase dashboard and execute:   - [`supabase_schema.sql`](supabase_schema.sql) — Creates the PostgreSQL schema, indexes, Realtime publications, and `product-images` storage bucket.   - [`supabase_enable_rls.sql`](supabase_enable_rls.sql) — Activates Row Level Security (RLS) policies on all tables.3. Copy your project's **URL** and **Publishable / Anon Key** into your `local.properties`.### 5. Build Commands- **Run Unit Tests**:  ```bash  ./gradlew testDebugUnitTest  ```- **Build Debug APK**:  ```bash  ./gradlew assembleDebug  ```  *Output: `app/build/outputs/apk/debug/app-debug.apk`*- **Build Production Release APK** (R8 Minified & Shrunk):  ```bash  ./gradlew assembleRelease  ```  *Output: `app/build/outputs/apk/release/app-release.apk`*---## 📄 LicenseThis project is licensed under the MIT License — see the [LICENSE](LICENSE) file for details.
